# Portfolio Freelance - Mawougnon Kpodji

## 1. Project Overview
- **Project Name**: Portfolio Mawougnon
- **Type**: Single-page React Application
- **Core Functionality**: Showcase Python/React freelance developer skills, services, and projects
- **Target Users**: Potential clients looking for freelance web developers

## 2. UI/UX Specification

### Layout Structure
- **Navigation**: Sticky header with smooth scroll links
- **Sections**: 
  1. Hero (Accueil)
  2. About (À propos)
  3. Services
  4. Projects
  5. Parcours
  6. Process
  7. Contact
- **Responsive**: Mobile-first, breakpoints at 768px and 1024px

### Visual Design

#### Color Palette
- **Primary**: #4F46E5 (Indigo vibrant)
- **Secondary**: #7C3AED (Purple)
- **Accent**: #F97316 (Orange bright)
- **Accent 2**: #10B981 (Emerald)
- **Background Light**: #FAFAFA
- **Background Cards**: #FFFFFF
- **Text Primary**: #1F2937
- **Text Secondary**: #6B7280

#### Typography
- **Headings**: "Poppins", sans-serif (weights: 600, 700)
- **Body**: "Inter", sans-serif (weights: 400, 500)
- **Hero Title**: 3.5rem (desktop), 2.5rem (mobile)
- **Section Titles**: 2.5rem (desktop), 1.75rem (mobile)

#### Spacing System
- Section padding: 100px vertical (desktop), 60px (mobile)
- Container max-width: 1200px
- Card padding: 24px
- Element gaps: 16px, 24px, 32px

#### Visual Effects
- Card shadows: 0 10px 40px rgba(79, 70, 229, 0.1)
- Hover transitions: 0.3s ease
- Gradient backgrounds on hero and accent sections
- Subtle animations on scroll (fade-in)

### Components

#### Navigation
- Logo/Name on left
- Menu links on right (desktop)
- Hamburger menu (mobile)
- Active section highlight
- Smooth scroll to sections

#### Hero Section
- Large gradient title
- Subtitle text
- Two CTA buttons with hover effects
- Availability indicator
- Decorative shapes/background elements

#### About Section
- Profile introduction text
- Photo placeholder or icon
- Skills highlights

#### Services Section
- 4 service cards in grid (2x2 desktop, 1 column mobile)
- Icons for each service
- Hover lift effect

#### Projects Section
- 2 main project cards (large)
- Stack tags
- Description, role, links
- Hover scale effect

#### Parcours Section
- Timeline or cards showing education and experience
- Company/university name
- Description

#### Process Section
- 4-step process cards
- Numbered steps
- Icons

#### Contact Section
- Contact text
- Email with copy button
- Social links (GitHub, LinkedIn)
- WhatsApp link (optional)

## 3. Functionality Specification

### Core Features
- Smooth scroll navigation
- Responsive design
- Interactive hover effects
- Animated section reveals
- Mobile menu toggle

### User Interactions
- Click nav links → smooth scroll to section
- Hover cards → lift/scale effect
- Click social links → open in new tab
- Mobile menu → toggle visibility

### Content
All content provided in French as specified in the task.
